About this tool

A portal address is 12 hex glyphs: Planet Index (1) + Solar System Index (3) + Y (2) + Z (3) + X (3). The galaxy itself is not part of the address — portals only connect within their own galaxy — which is why Galaxy is its own column here.

Named galaxies 1–50 and the biome descriptor list live at the top of js/visited_planets.js — edit those arrays directly to add more galaxies or swap in your own curated biome names.

Each row's Save button writes the entire table to one CSV file. In Chrome or Edge, use "Choose save file…" once and every Save after that overwrites the same file directly. In other browsers, Save downloads a fresh CSV each time.
